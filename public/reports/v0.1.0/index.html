What Worked Exceptionally Well — Validated v0.1.0 Architectural & Process Wins

1. Auto-Mounted `src/routes/*.ts` Discovery in `#13` Eliminated Future `src/server.ts` Collisions

By designing `Car 01-B` (`#13`, `PR #19`) to auto-discover route modules inside `src/routes/*.ts`, Waves 2, 3, and 4 (`#2, #8, #10, #12`) can add `/api/onboarding`, `/api/me`, `/api/stage/snapshot`, and `/api/introductions` in parallel without ever editing `src/server.ts`.

2. Freezing the 8-Table SQLite WAL Schema & Zod Contracts in `#1` First

Landing `src/contracts/*` and `src/db/schema.sql` (`Car 01-A`, `PR #20`) in Wave 1 gave all 4 Builder lanes (`Ariadne-Lane-A..D`) deterministic types and foreign-key invariants before any feature route or AI agent started coding.

3. Pairwise Source-Envelope Disjointness (`Envelope(A) ∩ Envelope(B) = ∅`) Across All 4 Cars

Sorting `v0.1.0` into 4 parallel workstreams (`#1`, `#13`, `#9`, `#14`) with zero overlapping source files allowed `Ariadne-INT` to merge `PR #18..#21` in `0.84h` (`50m 12s`) with zero source-code conflicts.

4. Standing Up the Public Roadmap & Sprint Reports Hub (`#14`) in Wave 1

Shipping `scripts/build-sprint-report.js`, `metrics_schema.py`, and `validate-sprint-report.py` in Wave 1 means every hackathon release (`v0.1.0`..`v1.0.0`) automatically publishes a judge-verifiable executive report at `/reports//`.

What Didn't Work & Concrete Guardrail Fixes Enacted in v0.1.0

1. SQLite Concurrent Write Contention Under Simultaneous SSE & Worker Writes

Default SQLite locking can throw `SQLITE_BUSY` when background GitHub ingestion writes collide with onboarding POST requests. Fix / Guardrail: Enforced `PRAGMA journal_mode = WAL; PRAGMA busy_timeout = 5000; PRAGMA foreign_keys = ON;` in `src/db/client.ts` (`#13`, `PR #19`).

2. SSE Client Connection Backpressure & Replay Cursor Integrity

Unclosed SSE streams or slow clients on `GET /api/events/stream` (`#9`) could buffer unboundedly or stall on withheld rows. Fix / Guardrail: Added backpressure pause/drain handling, 15s keep-alive comments, and cursor advancement past withheld rows in `Car 01-C` (`PR #21`).

3. Draft Report Isolation vs Published `/reports//` Static Serving

Pre-staged draft reports in `sprint-reports/` must never leak before tag certification, and draft-isolation tests must remain deterministic after publication. Fix / Guardrail: `src/server.ts` never aliases `sprint-reports/`, and `tests/server.test.ts` uses an isolated scratch `publicDir` to test draft unreachability independently of published reports.

4. Wrapper Sandbox `EPERM` on External CLI Symlinks

Cross-repo wrapper symlinks triggered macOS workspace sandbox `EPERM` errors in `Ariadne-Lane-C` and `Ariadne-Obsr`. Fix / Guardrail: Standardized on sanctioned host paths (`~/.tangleclaw/cli/bin/tc`, `/usr/bin/curl`, `/opt/homebrew/bin/gh`) across all lanes.
