### Security
- **Stage seed toggle refuses cross-site requests (`src/routes/stage-snapshot.ts`, follow-up to A-010 #10):** `POST /api/stage/seed-toggle` already rejected requests through the public tunnel, but any web page open in the presenter's browser could send a no-preflight `text/plain` POST to `127.0.0.1:3420` and flip the seed pool. It now requires `application/json` (415 otherwise) and rejects a foreign or opaque `Origin` and any `Sec-Fetch-Site` other than `same-origin`/`none` (403 `cross_site_request`). The presenter guard also requires a loopback `Host` (`localhost`, `127.0.0.1` or `[::1]`), because a DNS-rebinding page arrives on a loopback socket with matching `Origin`/`Host` and would otherwise pass every same-origin check. The stage page already sends JSON. Reported by Ariadne-Lane-C.

- **Deterministic five-component match scorer, anti-clone guard and Top-K selector (A-006, #6):**
  - `src/matching/scorer.ts`: `scorePair()` computes A-001's `ScoreBreakdown` using MATCH_SCORING_SPEC.md §3:
    - `capability_similarity`: confidence × proficiency cosine;
    - `need_offer_fit`: `max(cos(n_A, o_B), cos(n_B, o_A))`, where a need backed only by an open issue older than 120 days is weighted ×0.2 and carries a caveat; each direction is `dot(n_discounted, o) / (‖n_undiscounted‖·‖o‖)`, so the discount bites even when every need is stale (exactly ×0.2), yet a stale need the other side cannot meet never lowers the fit of a fresh one it can;
    - `complementarity`: complementary architectural layers, 1.0 with a shared domain and 0.5 without;
    - `novelty`: Jaccard distance of capability names;
    - `freshness`: median age of the cited projects.
