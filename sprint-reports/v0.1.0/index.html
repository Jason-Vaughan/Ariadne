What Worked Exceptionally Well — Validated v0.1.0 Architectural & Process Wins

1. Auto-Mounted `src/routes/*.ts` Discovery in `#14` Eliminated Future `src/server.ts` Collisions

By designing `Car 01-B` (`#14`, `PR #18`) to auto-discover route modules inside `src/routes/*.ts`, Waves 2, 3, and 4 (`#2, #8, #10, #12`) can add `/api/onboarding`, `/api/me`, `/api/stage/snapshot`, and `/api/introductions` in parallel without ever editing `src/server.ts`.

2. Freezing the 10-Table SQLite WAL Schema & TypeScript DTOs in `#1` First

Landing `src/contracts/*` and `src/db/schema.sql` (`Car 01-A`, `PR #17`) in Wave 1 gave all 4 Builder lanes (`Ariadne-Lane-A..D`) deterministic types and foreign-key invariants before any feature route or AI agent started coding.

3. Pairwise File-Envelope Disjointness (`Envelope(A) ∩ Envelope(B) = ∅`) Across All 4 Cars

Sorting `v0.1.0` into 4 solo workstreams (`#1`, `#14`, `#9`, `#15`) with zero shared files allowed `Ariadne-INT` to merge `PR #17..#20` back-to-back with zero merge conflicts.

4. Standing Up the TangleClaw Python Reporting Pipeline (`#15`) in Wave 1

Installing `metrics_schema.py`, `validate-sprint-report.py`, and `build-ariadne-roadmap.py` on PortHub `:3422` in Wave 1 means every subsequent hackathon release (`v0.2.0`..`v1.0.0`) automatically publishes a judge-verifiable executive report.

What Didn't Work & Concrete Guardrail Fixes Enacted in v0.1.0

1. SQLite Concurrent Write Contention Under Simultaneous SSE & Worker Writes

Default SQLite locking can throw `SQLITE_BUSY` when background GitHub ingestion writes collide with onboarding POST requests. Fix / Guardrail: Enforced `PRAGMA journal_mode = WAL; PRAGMA busy_timeout = 5000; PRAGMA foreign_keys = ON;` in `src/db/client.ts` (`#14`).

2. SSE Client Connection Cleanup on Mobile Safari Tab Backgrounding

Unclosed SSE response streams in `src/routes/events.ts` (`#9`) can accumulate stale listeners when mobile clients sleep. Fix / Guardrail: Added `req.on('close')` listener pruning and 15-second heartbeat comments in `Car 01-C` (`PR #19`).

3. Version Tuple Comparison in `validate-sprint-report.py` for Pre-1.0 (`v0.x.y`) Releases

TangleClaw's validator originally gated `v2.0.0` canonical checks on `version >= (5, 65, 0)`. Fix / Guardrail: Updated `requires_v2_canonical_metrics()` in `validate-sprint-report.py` so all Ariadne `v0.1.0+` reports enforce the full `v2.0.0` 8-timestamp and 3-tier cost contract.

4. TangleClaw Dashboard `OPERATOR_ONLY` Gate on `POST /api/projects`

Programmatic project creation from a PM session returns `403 OPERATOR_ONLY`. Fix / Guardrail: Packaged a 1-paste Browser DevTools Console script in `FLEET_PROVISIONING_PACK.md` plus `scripts/propose-fleet-rules.sh` so the Operator can spawn all 8 fleet lanes in 3 seconds.
