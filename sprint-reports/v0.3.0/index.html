05 Sprint Post-Mortem, 16-Point Governance Audit & 4 Maintenance Gates

Empirical findings from Ariadne-Obsr, Ariadne-PM, Ariadne-PRR, and Ariadne-Arc across Sprint v0.3.0.

16 / 16 Rule #283 Measures Audited · 4 / 4 Gates Complete

✅ What Worked Exceptionally Well (4 Core Wins)

1. Two-Stage Deterministic + Gemini 2.5 Flash Pattern (`#4`, `#7`)

Separating Stage 1 (deterministic, `<50 ms`, zero network dependencies) from Stage 2 (Gemini 2.5 Flash with a `4s` timeout and strict citation verification) guaranteed that every participant and match pair gets a complete, contract-valid fingerprint and explanation card immediately, even when no API key is configured or an LLM call times out.

2. Pre-Merge R-Gate Caught Stage 1 Private-Detail Leakage (`#32`)

In `PR #32` (`A-007`), `Ariadne-PRR` identified that Stage 1 copied participant-submitted goal text verbatim into match explanation cards before bilateral intro approval. `Ariadne-Lane-C` added a shared private-detail scrubber that redacts emails, `@handles`, phones, contact cards, and non-evidence links across both Stage 1 cards and Stage 2 prompts.

3. Eliminating the `A-006` 5ms Timing Flake via Precomputation (`#33`)

When concurrent test runs briefly pushed the 30-candidate `A-006` scorer benchmark near its `5 ms` ceiling, `Ariadne-Lane-C` shipped `PR #33` (`@ 2998fd6`) to precompute per-profile token sets and domain maps once outside the pair loop, dropping 30-pair scoring latency well below `1 ms`.

4. Exact-Second `T_eng = t7 - t2` Validator Hardening (`#30`)

During Gate 4 review of `PR #30`, `Ariadne-INT` and `Ariadne-PRR` caught that early-rounded `T_eng` hours (`0.40h` vs `1,427s = 0.3964h`) shifted derived throughput and `ADE_v1`. `Ariadne-Obsr` upgraded `validate-sprint-report.py` and `test_validate_sprint_report.py` (`12/12` tests) to enforce exact-second derivation (`<= 0.01` tolerance).

⚠️ What Didn't Work & Proven Fixes for Next Sprint (4 Guardrails)

1. Mid-Flight Withdrawal Race in `persistAnalysis()` (`PR #27` → `#35`)

If a participant withdrew consent while an asynchronous Stage 2 capability analysis was in flight, `persistAnalysis()` could write claims for the withdrawn row. Fix / Guardrail: `PR #35` (`@ 7a9baed`) hardened `persistAnalysis()` to check `consent_status === 'granted'` and `analysis_state !== 'withdrawn'` inside the transaction, returning `skipped: 'consent_withdrawn'`.

2. Schemeless Hostnames in Stage 2 Grounding Gate (`PR #32`)

Initial URL checks in `A-007` matched `http(s)://` and `github.com/...` paths but allowed bare schemeless hostnames (e.g., `gitlab.com/x` or `evil.ru`). Fix / Guardrail: `Ariadne-Lane-C` tightened `src/matching/explanation-agent.ts` (`#32` and follow-up `#36`) so every dotted host-like token outside pathless code/file names (`Node.js`, `main.py`) is verified against the pair's receipts.

3. Early Rounding of `T_eng` Before Computing Throughput & `ADE_v1`

Computing `Throughput = W / round(T_eng, 2)` instead of `W / (eng_seconds / 3600)` introduced a `0.09/hr` drift in `v0.2.0`. Fix / Guardrail: `validate-sprint-report.py` now computes `t_eng_exact = (t7 - t2).total_seconds() / 3600.0` and rejects any report whose throughput, allocated cost, or `ADE_v1` diverges by `> 0.01` (`test_12`).

4. Pipelined Wave 4 Merges Advancing `main` During Report Review

Because Wave 4 cars (`#31`, `#34`, `#36`) merged onto `main` while `PR #30` was in review, `CHANGELOG.md` required ancestor syncs. Fix / Guardrail: `Ariadne-INT` holds `main` stable during final exact-head `R/A/O` report verification so report PRs merge in a single pass.
