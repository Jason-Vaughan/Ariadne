What Worked Exceptionally Well — Validated v0.2.0 Architectural & Process Wins

1. Pipelined Wave 2 Dispatch Cut Inter-Release Cadence to 23 Minutes (`0.38h`)

As each Builder lane completed its Wave 1 Car (`Lane-A`, `Lane-B`, `Lane-D`), `Ariadne-PM` immediately dispatched its Wave 2 Car (`#2`, `#3`, `#10`), yielding a `47s` (`0.01h` / `3.3%`) `t2→t7_prev` branch-commit overlap (`10m 30s` `t1` dispatch overlap) and delivering `v0.2.0` just 23 minutes (`0.38h` cadence; `0.40h` / `23m 47s` `T_eng`) after `v0.1.0`.

2. Zero `src/server.ts` Contention Across `/join` (`#2`) and `/stage` (`#10`)

Both `src/routes/onboarding.ts` (`PR #22`) and `src/routes/stage-snapshot.ts` (`PR #24`) mounted automatically via `src/server.ts`'s directory loader (`#13`), validating the Wave 1 spine design with zero server entrypoint edits.

3. Multi-PAT Rotation, SSRF Guard & 24h SQLite Cache in `#3` (`PR #23`)

`Ariadne-Lane-B` shipped a bounded GitHub + public website connector that completes in `416ms` (3 API calls on live `octocat` smoke test), answers cache hits in `<10ms`, and blocks private/loopback/tailnet SSRF and DNS rebinding.

4. Dual-Gate Pre-Merge Catches on Website Cache & Stale-Need Discount

`Ariadne-PRR` and `Ariadne-Arc` caught 4 nuanced edge cases before merge: website-delta cache invalidation (`PR #23`), VIP pre-warm admission on a full room (`PR #22`), non-object JSON body handling (`PR #24`), and stale-need discount math without penalizing fresh fits (`PR #26`).

What Didn't Work & Concrete Guardrail Fixes Enacted in v0.2.0

1. Cached GitHub Snapshot Missing Newly Added Participant Website

When a VIP/judge handle was pre-warmed without a website and later registered at `/join` with a website URL, the 24h cache initially returned the website-less snapshot. Fix / Guardrail: Updated `src/github/cache.ts` (`84460f3` in `PR #23`) to fetch only the new website and recompute the 6-axis fingerprint while preserving the snapshot TTL.

2. Stale-Issue Discount Normalization in `need_offer_fit` (`#6`)

Normalizing the discounted need vector by its own norm caused a single stale need to cancel out its `×0.2` discount, while normalizing by the full undiscounted norm penalized fresh needs when an unrelated stale need was present. Fix / Guardrail: `PR #26` (`223bca2`) computes `dot(n_discounted, o) / (||n_undiscounted|| · ||o||)` on active dimensions and fails closed on unconsented profiles.

3. Shared `CHANGELOG.md` Rebase Churn on Rapid Back-to-Back Merges

Because 4 Wave 2 PRs (`#23, #22, #24, #26`) merged within 12 minutes, open branches touching `CHANGELOG.md` (`PR #25`) needed quick `origin/main` merges. Fix / Guardrail: `Ariadne-INT` prioritizes merging ready O-Gate report PRs between feature merges so report branches don't accumulate `CHANGELOG.md` conflicts.

4. Pre-Staged Generator Prose Drift vs. Authoritative `metrics_schema.py`

`Ariadne-PRR` caught that pre-staged prose in `gen_v010.py` still cited placeholder PR numbers while `metrics_schema.py` had the real numbers. Fix / Guardrail: All report generators (`gen_v010.py`, `gen_v020.py`) now bind every PR number, SHA, LOC count, and `T_eng` figure directly to the canonical `metrics_schema.py` values and undergo a post-generation regex audit.
