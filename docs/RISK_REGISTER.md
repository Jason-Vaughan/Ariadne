# Risk Register & Mitigation Matrix — ARIADNE (`ARIADNE-HACK-2026`)
*Amended: Web-Only Self-Hosted Hackathon MVP*

| ID | Risk Category | Threat Description | Likelihood | Impact | Pre-Engineered Mitigation & Fallback |
|---|---|---|---|---|---|
| **R-01** | **Venue Wi-Fi / Proxy Buffering** | Conference Wi-Fi or reverse proxy buffers chunked SSE streams or drops packets during the stage demo. | **High** | **High** | 1. Dual-transport live updates: SSE (`GET /api/events/stream`) automatically falls back to JSON polling (`GET /api/events/poll?after=<seq_id>`) every `3s`.<br>2. Stage laptop can render `/stage` directly from `http://127.0.0.1:3420/stage` on the host with `0ms` network latency, while attendees connect over cellular via the narrow HTTPS tunnel. |
| **R-02** | **Control-Plane Exposure via Public Tunnel** | Misconfigured tunnel exposes TangleClaw's `:3102` server, `:3100` ttyd, `:8443` Caddy ingress, or `:3009` Medusa hub. | **Low** | **Critical** | 1. Never use `tailscale funnel` on `:8443`.<br>2. Bind Ariadne exclusively to `127.0.0.1:3420` (PortHub-registered) and point `cloudflared tunnel --url http://127.0.0.1:3420` solely at `3420`.<br>3. Automated `A-014` security test verifies no TangleClaw env vars or ports are reachable through the Ariadne process. |
| **R-03** | **GitHub API Rate Limits** | Unauthenticated GitHub REST calls cap at `60 req/hr` per IP. | **High** (if unauthenticated) | **Critical** | 1. Authenticated server-side `ARIADNE_GITHUB_TOKEN` (`5,000 GraphQL points/hr`).<br>2. Single-query GraphQL snapshot uses **1 point per user**.<br>3. SQLite `github_snapshots` table caches profiles for `30 minutes` (`0` points on repeat views). |
| **R-04** | **LLM Latency or Timeout Under Load** | Concurrent participant submissions slow down AI profile/match synthesis. | **Medium** | **High** | 1. In-process SQLite job queue decouples HTTP intake (`< 15ms`) from background AI tasks.<br>2. Hard `12s` timeout per AI task; on timeout, `Car 1-B` and `Car 1-C` fall back to deterministic repo metadata extraction and template synthesis. |
| **R-05** | **GitHub Account Impersonation** | Someone enters another person's GitHub handle and tries to send outbound introduction requests. | **Medium** | **High** | Two-Tier Identity (`PRIVACY_AND_SECURITY.md`): unverified username entry allows read-only profile preview, while outbound `Interested` proposals and Mutual Intro Room unlocking require `ownership_verified === true` via 1-click GitHub OAuth or bio challenge token. |
| **R-06** | **Privacy / Unconsented Stage Exposure** | An attendee scans the QR code to try the app but does not want their handle/photo projected on the 16:9 screen. | **Medium** | **High** | 1. Mandatory opt-in consent before any GitHub fetch.<br>2. Stage nodes default to pseudonymous (`Thread-XXXX`) unless `public_display_consent` is checked.<br>3. Stage hotkey `S` forces 100% pseudonymity globally. |
| **R-07** | **Prompt Injection via Untrusted GitHub Content** | A repository `README.md` or open issue contains adversarial prompt text. | **Low–Med** | **High** | 1. Strip HTML/scripts and truncate excerpts (`<= 3,500 chars`).<br>2. Wrap external text in `<untrusted_github_evidence>` tags.<br>3. Verification Gate checks that every cited `evidence_url` exists in the participant's SQLite `evidence_receipts` rows. |
| **R-08** | **Intra-Wave Merge Collisions Across Builders** | Four parallel Builder lanes conflict on `CHANGELOG.md`, `package.json`, or shared contracts. | **Medium** | **High** | 1. Freeze `src/contracts/*` and `package.json` in `Train 0 (v0.1.0)` at `10:15 AM`.<br>2. Bundle related issues into file-disjoint Cars (`TC Rule #294`).<br>3. Builders write `changelog.d/<car>.md` fragments instead of editing root `CHANGELOG.md`. |
| **R-09** | **SQLite Lock Contention or Corruption on Cutover** | Concurrent reads/writes or an abrupt process restart during a Train cutover. | **Low** | **High** | Enable `PRAGMA journal_mode = WAL; PRAGMA busy_timeout = 5000;` in `Car 0-INT`, and run atomic `sqlite3 .backup` before every Train cutover (`v0.1.0`..`v1.0.0`). |
