In-process SQLite job queue decouples HTTP intake (< 15ms) from background AI tasks.<br>2. Mandatory opt-in consent before any GitHub fetch.<br>2. Stage nodes default to pseudonymous (Thread-XXXX) unless public_display_consent is checked.<br>3. Stage hotkey S forces 100% pseudonymity globally.
R-07Prompt Injection via Untrusted GitHub ContentA repository README.md or open issue contains adversarial prompt text.Low–MedHigh1. Strip HTML/scripts and truncate excerpts (<= 3,500 chars).<br>2. Wrap external text in <untrusted_github_evidence> tags.<br>3. Verification Gate checks that every cited evidence_url exists in the participant's SQLite evidence_receipts rows.
