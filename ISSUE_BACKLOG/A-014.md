# [chore] A-014: Production deployment and operational resilience

- **Issue ID:** `A-014`
- **Priority:** `P0`
- **Assigned Lane:** `Ariadne-INT` (Integrator)
- **Milestone:** `Wave 0 Bootstrap & Wave 4 Hardening (v0.0.1 -> v1.0.0-hackathon)`
- **Dependencies:** `A-001`

## 1. Description
Configure and verify the public HTTPS production deployment on Vercel (`jason-vaughan`), managed serverless database persistence (`Neon` / `Turso`), bounded background job execution (`waitUntil` + idempotent `/api/worker/tick`), health/readiness endpoints (`GET /api/health`), secret isolation, and 1-command rollback procedure.

## 2. Rationale
Ariadne must be publicly reachable via mobile QR scan over cellular or venue Wi-Fi with zero dependency on the Operator's laptop or TangleClaw's loopback control plane, and must survive any last-minute deployment issue via instant rollback.

## 3. Dependencies
- Depends on `A-001` (core repository & schema initialization).

## 4. Implementation Boundaries
- **In Scope:** Vercel project configuration (`vercel.json`), database connection pooling, bounded async job runner (`src/lib/jobs/runner.ts`), `GET /api/health` readiness endpoint, environment variable verification script, and rollback runbook check.
- **Out of Scope:** Exposing any local machine ports (`tailscale funnel`) or modifying TangleClaw infrastructure.

## 5. Acceptance Criteria
- [ ] Public HTTPS URL serves `/join`, `/me`, and `/stage` with valid TLS and `< 300ms` TTFB.
- [ ] `GET /api/health` reports database connectivity, GitHub API rate-limit status (`remaining > 0`), and worker queue depth without leaking secrets or stack traces.
- [ ] Background profile analysis and match evaluation jobs recover automatically if a serverless invocation restarts (`leased_until` timeout recovery).
- [ ] Previous working deployment alias can be restored in `< 30 seconds` via `vercel rollback`.

## 6. Test Requirements
- Integration tests for `GET /api/health`, stalled-job lease recovery in `src/lib/jobs/runner.ts`, and verification that error responses strip internal stack traces and environment variables.

## 7. Security & Privacy Considerations
- Store all secrets exclusively in Vercel encrypted environment variables (`Production` / `Preview`).
- Ensure zero TangleClaw or Operator personal tokens exist in the deployment environment.

## 8. Expected Demonstration Impact
Guarantees rock-solid uptime during the 6:00–8:00 PM Pacific live stage demonstration and audience QR onboarding wave.
