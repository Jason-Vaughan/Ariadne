# [feature] A-017: Medusa coordination adapter (Optional)

- **Issue ID:** `A-017`
- **Priority:** `P2 / Optional`
- **Assigned Lane:** `Ariadne-Lane-C` (Builder C — Stretch Only)
- **Milestone:** `Wave 3 — Optional Stretch`
- **Dependencies:** `A-007`

## 1. Description
Implement an optional, strictly isolated internal Medusa coordination adapter (`src/lib/medusa/adapter.ts`) that allows bounded agent-to-agent negotiation between Participant A's representative profile agent and Participant B's representative profile agent over a local/isolated switchboard channel during candidate evaluation, falling back transparently to direct in-process `A-007` evaluation whenever Medusa is disabled (`ENABLE_MEDUSA_ADAPTER !== 'true'`).

## 2. Rationale
Demonstrates how Ariadne's matching architecture can plug into Medusa's A2A messaging protocol for multi-turn capability verification without placing Medusa on the public critical path.

## 3. Dependencies
- Depends on `A-007` (Match Research & Proposal Agent).
- **Shedding Rule:** First item shed if Wave 1 or Wave 2 runs behind schedule by `> 15 minutes`.

## 4. Implementation Boundaries
- **In Scope:** `src/lib/medusa/adapter.ts` behind feature flag `ENABLE_MEDUSA_ADAPTER=false` (default off in public Vercel environment), bounded 2-turn negotiation transcript summary, and 3-second circuit breaker fallback to standard `A-007`.
- **Out of Scope:** Internet-wide Medusa federation, exposing Medusa's loopback ports (`3009`/`3010`), or embedding Medusa shared secrets in public client bundles.

## 5. Acceptance Criteria
- [ ] Disabled by default (`ENABLE_MEDUSA_ADAPTER=false`); application runs 100% of core flows when disabled or unreachable.
- [ ] When enabled in a local/bridged environment, conducts a bounded 2-message structured capability exchange (`propose_thesis` → `verify_evidence`) and attaches the verified receipt to the `MatchProposal`.
- [ ] Zero Medusa shared secrets, internal workspace IDs, or loopback endpoints are exposed to public users.

## 6. Test Requirements
- Unit tests verifying circuit-breaker fallback (`< 3s` timeout falls back cleanly to standard `A-007` evaluation) and secret-redaction checks on emitted event payloads.

## 7. Security & Privacy Considerations
- Never expose `127.0.0.1:3009` or Medusa's shared secret outside the isolated host environment.
- Never allow untrusted GitHub README text to construct raw Medusa control frames.

## 8. Expected Demonstration Impact
Provides an optional bonus narrative for judges interested in A2A agent negotiation protocols, with zero risk to the core hackathon deliverable.
